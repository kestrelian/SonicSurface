FAQ

Question: How to set Quartus to generate pof?

 Answer:

In assignments -- device -- device and pin option, and in configuration option, check Use Configuration device choose the chip to configure.
Choose the configuration scheme as Active Serial.

{{{5}}}


Question: The newly bought board and downloader program in Quartus, always prompt the following error?

 Answer:
Possible reason:

The version of Quartus 11 (this version is relatively stable) that is supported by the CD is not used. Some users encounter this error when using the version of Quartus 9. After installing version 11, the problem is solved.
